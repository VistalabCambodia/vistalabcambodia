# Security policy

## Supported version

Security fixes are made on the `main` branch.

## Reporting a vulnerability

Please report security issues through GitHub's **Report a vulnerability** feature in the repository's **Security** tab. This sends a private report to the maintainers. Do not post credentials, private customer data, or an exploitable vulnerability in a public issue.

If private vulnerability reporting is unavailable, contact the repository owner privately through GitHub before sharing technical details publicly.
